# 🏨 Hospitality Analysis Dashboard | Power BI

## 📌 Project Overview
This project focuses on analyzing hotel booking and revenue data using Microsoft Power BI to generate meaningful business insights and support data-driven decision-making in the hospitality industry.

The dashboard provides an interactive view of key hospitality metrics, helping users understand booking performance, revenue trends, occupancy, and guest satisfaction.

## 🎯 Project Objectives
- 📊 Analyze overall hotel booking and revenue performance.
- 🏨 Monitor occupancy rates and room utilization.
- 💰 Evaluate key financial KPIs such as ADR, RevPAR, and Realisation %.
- 🌆 Compare performance across properties and cities.
- ⭐ Understand guest ratings and customer satisfaction.
- 💡 Support better business decisions through interactive visualizations.

## 🛠️ Tools & Technologies
- 📊 Microsoft Power BI
- 🧮 DAX (Data Analysis Expressions)
- 🔄 Data Modeling
- 📈 Interactive Data Visualization
- 🧹 Data Cleaning and Transformation

## 📈 Key Features
- 📅 Interactive filters and slicers.
- 💰 Revenue and booking performance analysis.
- 🛏️ Occupancy and room-class analysis.
- 🌆 Property and city-level comparisons.
- ⭐ Guest rating analysis.
- 📊 KPI cards for quick performance monitoring.
